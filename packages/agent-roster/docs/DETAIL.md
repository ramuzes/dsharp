The roster keeps one profile-wide library of role templates and turns it into one-click team building. A "+"-menu command opens a member-spawn modal: pick a template or write a one-off custom role, name the member, optionally pick a model (the session model by default) and an initial task. AI-assisted drafting lives in the same modal's custom form — it is configured in Settings > Agent roster (an enable toggle plus the draft model; enabling requires picking a model) and drafts only propose: you review and save or drop the result. The same Settings page manages the roster (create / edit / delete, per-template default model). Templates persist through the host's storageDomain, roster_template_save and roster_template_list expose the library to the model as agent tools, and spawned members are ordinary subagents on the caller's tree, visible in the standard Subagents panel.
