The roster keeps one profile-wide library of role templates and turns it into one-click team building: a "+"-menu command opens a member-spawn modal (pick a template or write a one-off custom role, name the member, optionally pick a model — the session model by default — and an initial task), an AI-draft area drafts new template proposals through one reusable draft session per workspace (proposals only: you save or drop the result yourself), and the Plugins page hosts a roster manager card for create / edit / delete round-trips. Templates persist through the host's storageDomain, roster_template_save and roster_template_list expose the library to the model as agent tools, and spawned members are ordinary subagents on the caller's tree, visible in the standard Subagents panel.
