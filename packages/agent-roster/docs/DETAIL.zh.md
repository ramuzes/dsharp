花名册维护一份全 profile 共用的角色模板库，把组建团队变成一键操作。会话内的“+”菜单打开成员生成弹窗：选择模板或当场填写一次性角色，为成员命名，可选模型（默认继承会话模型）与初始任务。AI 代笔位于该弹窗的自定义表单中——其开关与草稿模型在 设置 > Agent roster 中配置（开启即需选择模型），且草稿仅作建议：由你审阅后保存或丢弃。同一设置页管理花名册（增删改、每模板默认模型）。模板经宿主 storageDomain 持久化，roster_template_save 与 roster_template_list 将模板库暴露给模型，生成的成员即调用方树上的普通子代理，可在标准 Subagents 面板中查看。
